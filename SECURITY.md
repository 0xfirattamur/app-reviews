# Security Policy

## Supported versions

The latest released version of `app-reviews` receives security updates. Older versions do not.

## Reporting a vulnerability

Please report vulnerabilities through [GitHub Security Advisories](https://github.com/0xfirattamur/app-reviews/security/advisories/new) so the report stays private until a fix ships. Don't open a public issue.

Helpful to include:

1. A description of the vulnerability and its impact
2. Steps to reproduce (a proof-of-concept script is ideal)
3. The `app-reviews` version, OS, and Python version

You'll get an acknowledgement within a few days. Please give us a chance to ship a fix before disclosing publicly.
